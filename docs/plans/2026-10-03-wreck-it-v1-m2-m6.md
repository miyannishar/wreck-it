## CLI commands

### `wreck-it discover [--root <dir>] [--json]`
Static scan, no network. Writes `.wreck-it/discovery.json` and prints a one-screen summary (or the JSON with `--json`).

```ts
interface Discovery {
  generatedAt: string;
  frameworks: ("nextjs-app" | "nextjs-pages" | "express" | "fastify" | "hono" | "react-router" | "sveltekit" | "remix")[]; // [] = unknown
  baseUrl?: string;        // guessed: http://localhost:<port> from dev script / framework default
  devScript?: string;      // e.g. "npm run dev"
  pages: { path: string; file: string; dynamic: boolean }[];          // "/products/[id]" style params
  api: { method: string; path: string; file: string; line?: number }[]; // method "ANY" when unknown
  forms: { file: string; line: number; fields: string[]; action?: string }[];
  auth: { kind: "none" | "next-auth" | "clerk" | "supabase" | "lucia" | "better-auth" | "passport" | "custom-session" | "jwt" | "unknown"; evidence: string[] };
  database?: { kind: string; url?: string; remote: boolean };       // from .env* DATABASE_URL etc.; url is redacted (no password)
  warnings: string[];
}
```
Report consumes `pages[].path` and `baseUrl` (already implemented).

### `wreck-it preflight [--url <u>] [--i-own-this] [--wait <sec>] [--root <dir>] [--json]`
Checks: target allowed; app reachable (polls up to `--wait`, default 0); Playwright MCP configured for any known agent; `.gitignore` covers `.wreck-it/`. Prints JSON `{ url, allowed, reason, reachable, status?, devScript?, playwrightMcp: { found: boolean, sources: string[] }, installHints: Record<agent, string>, warnings: string[] }`. Exit 0 when allowed+reachable, 3 when the target is refused, 4 when unreachable. `--url` defaults to config `baseUrl`, then discovery `baseUrl`, then `http://localhost:3000`.

### `wreck-it oddity-script`
Prints a single JS arrow function expression (no trailing semicolon) suitable for Playwright MCP `browser_evaluate`'s `function` argument. Evaluating it resolves to:
```ts
{ url: string; signals: { kind: "rendered-placeholder" | "broken-image" | "dead-link" | "horizontal-overflow" | "overlap" | "slow-lcp" | "empty-page"; detail: string; selector?: string }[] }
```

### `wreck-it sweep [--base-url <u>] [--viewports 1280x800,390x844] [--record] [--no-a11y] [--i-own-this] [--root <dir>] [--json]`
(Added after the first eval runs.) Headless Chromium visits every static page in discovery and one real URL per dynamic route (taken from links), at each viewport. It logs in first with config `accounts[0]` and never visits logout-like paths. On each page it runs `ODDITY_SCRIPT`, captures same-origin 5xx responses and console errors, and runs axe on the first viewport. With `--record`, each root cause (placeholder token, image src, link href, mobile overflow per route, 5xx endpoint, axe rule) is re-checked in a fresh context and recorded once with persona `sweep`. Re-runs skip titles already recorded. Writes `.wreck-it/sweep.json`.

### `wreck-it a11y <url...> [--storage-state <file>] [--viewport WxH] [--record] [--i-own-this] [--root <dir>] [--json]`
Runs axe-core in headless Chromium (`playwright` package). Writes `.wreck-it/a11y/<slug>.json`. With `--record`, adds one finding per violation rule per URL: category `accessibility`, severity critical→high, serious→medium, moderate/minor→low, `reproduced: true`, persona `a11y-scan`, steps `[{goto}]`, assertions `[]`. Missing browser → WreckError telling the user to run `npx playwright install chromium`.

### `wreck-it load <url> [--profile ramp|spike|soak] [--method GET] [--pid <n>] [--step-duration <s>] [--max-connections <n>] [--soak-duration <s>] [--header k:v]... [--i-own-this] [--root <dir>] [--json]`
autocannon. Writes `.wreck-it/load/<slug>-<profile>.json` matching `LoadResultSchema` (`src/load/types.ts`). Non-GET/HEAD refused (exit 2) unless config `allowMutatingLoad`. Warns when discovery/env database looks remote. Memory sampled via `ps -o rss= -p <pid>` (pid from `--pid`, else `lsof -ti tcp:<port> -sTCP:LISTEN` when available). On crash it waits up to 30 s for recovery, sets `crashed/recovered`, and **adds a critical `performance` finding automatically** (step `{action:"http"}` replaying a GET, `reproduced: true`). Breaking points and leaks are left to the `wreck-load` skill to record after tracing.

## Skills (`skills/<name>/SKILL.md`, Agent Skills frontmatter `name` + `description`)
`wreck-it` (orchestrator), `wreck-personas`, `wreck-explore`, `wreck-chaos`, `wreck-load`, `wreck-trace`. Skills call only `npx wreck-it …`, shell, and standard Playwright MCP tools (`browser_navigate`, `browser_snapshot`, `browser_click`, `browser_type`, `browser_fill_form`, `browser_select_option`, `browser_press_key`, `browser_evaluate`, `browser_take_screenshot`, `browser_console_messages`, `browser_network_requests`, `browser_navigate_back`, `browser_resize`, `browser_tabs`, `browser_wait_for`, `browser_close`).

## Plugin (repo root)
`.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json`, `commands/wreck.md`, `agents/wreck-persona.md`, `.mcp.json` with `wreck-browser-1..3` (`npx @playwright/mcp@latest --isolated`), `skills/` shared. `AGENTS.md.snippet` for agents without skills.

## Buggy app (`examples/buggy-app`)
Next.js 16 + React 19, in-memory store, no external services. `wreck-manifest.json` lists seeded bugs `{ id, title, category, severity, route, file, keywords[] }`. `scripts/eval.mjs [--root examples/buggy-app]` matches `.wreck-it/findings/*.json` to the manifest (route + (source.file or keyword hit)) and prints recall, false positives, and pass/fail against the release gate (≥80% recall, ≤2 FP).
