# wreck-it v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship wreck-it v1. It has two parts: agent-agnostic skills, and a deterministic `wreck-it` npm CLI. Together they let any coding agent test a local web app (normal user, ICP personas, chaos, accessibility, load) and produce a scored bug report with source locations and regression Playwright tests.

**Architecture:** Skills (Markdown, Agent Skills standard) hold the judgment work: personas, browser exploration via Playwright MCP, bug triage and source tracing. The TypeScript CLI holds everything deterministic: discovery, finding schema and storage, oddity/a11y/load checks, scoring, report rendering and test generation. A Claude Code plugin wrapper adds `/wreck` and parallel persona subagents. `examples/buggy-app` (Next.js) has ~17 seeded bugs; it is both the demo and the eval benchmark.

**Tech Stack:** Node ≥ 20 (dev machine has 26), npm workspaces, TypeScript ~5.9, tsup, vitest, zod 4, commander 14 (15 needs Node ≥ 22.12), autocannon 8, axe-core 4, playwright, Next.js 16 + React 19 (buggy-app only). Do NOT use TS 7, because tsup's dts build needs the TS 5 JS API.

**Spec:** `docs/specs/2026-10-03-wreck-it-design.md`. Read it before starting any task.

## Scope note

The security module (spec §6.5) is **deferred out of v1** and tracked in `TODO.md`. Do not build security checks, security skills or security seed bugs. The `security` category stays in the schema and score constants so the module can be added later.

## Global Constraints

- **No git commits, pushes, or branch operations.** The user's global rule forbids committing without an explicit request. Every task ends at "tests pass", not "commit".
- Package name: `wreck-it` (free on npm as of 2026-10-03). Binary name: `wreck-it`.
- The CLI is ESM (`"type": "module"`) with `engines.node: ">=20"` and TypeScript `strict: true`.
- The CLI never calls an LLM and never needs an API key.
- All CLI commands accept `--root <dir>` (default `process.cwd()`). All state lives in `<root>/.wreck-it/`.
- Network targets must pass `isAllowedTarget` (localhost, loopback or private ranges) unless config `iOwnThis: true` or the flag `--i-own-this` is set.
- Load testing uses only `GET`/`HEAD` unless config sets `allowMutatingLoad: true`.
- Unit tests never reach the public internet. Local HTTP servers on `127.0.0.1:0` are fine.
- Score constants (verbatim from spec):
  - Deductions: critical −25, high −10, medium −4, low −1.
  - Caps: functional 60, security 50, performance 40, chaos 30, ux 20, oddity 15, accessibility 15.
  - Any reproduced critical caps the score at 49. Floor 0.
  - Bands: 0–49 Not ready · 50–74 Risky · 75–89 Almost there · 90+ Ship it.
- Categories (verbatim): `functional | ux | oddity | chaos | performance | security | accessibility`. Severities: `critical | high | medium | low`.
- Tagline (verbatim): "Wreck your app before your users do."
- No Disney / Wreck-It Ralph imagery or references.
- When unsure of a library API (zod 4, commander 14, autocannon 8, Playwright, Next 16), query context7 docs before guessing.

## Spec refinements made while planning (binding)

1. Finding `steps[].target` is a **structured locator** (`{by:"role",role,name}` | `{by:"label"|"text"|"placeholder"|"testId"|"css", value}`) instead of a selector string. This lets `gen-tests` emit idiomatic `getByRole`/`getByLabel` code.
2. Findings gain `assertions[]`, which describe the **correct** behavior. Generated tests assert these, so they fail while the bug exists. Findings without assertions generate `test.fixme`.
3. autocannon reports p50/p90/p97.5/p99 but no p95. Reports show **p50 / p90 / p99**.
4. axe-core is too large to paste through an MCP `evaluate` call. Accessibility scanning is therefore a CLI command (`wreck-it a11y`) that drives its own headless Chromium via the `playwright` package.
5. CLI commands added beyond the spec: `preflight`, `run`, `finding update|list`, `schema`, `a11y`. The spec's `oddity-scan` is named `oddity-script`, because it prints a script.
6. Claude Code plugin files live at the repo root in the standard plugin layout (`.claude-plugin/plugin.json`, `commands/`, `agents/`, `.mcp.json`), not inside `.claude-plugin/`. `.mcp.json` declares three isolated Playwright MCP servers (`wreck-browser-1..3`). Up to 3 persona subagents can then run in parallel without sharing a browser.

## Review Focus

1. **Finding text containing HTML markup.** Chaos findings record raw inputs like `<b>x</b>`. `report.html` must escape every interpolated string, so markup appears as text and never renders. Test in Task 7.
2. **Tricky targets.** For `http://localhost.evil.com`, `http://127.0.0.1.nip.io`, `https://example.com`, `http://[::1]:3000` and `http://0x7f000001`, only true loopback/private hosts are allowed without `iOwnThis`. Malformed URLs are rejected, not thrown. Test in Task 9.
3. **Corrupt or partial `.wreck-it/` state.** With malformed finding JSON, missing dirs, zero findings or missing screenshot files, `report` still renders, lists warnings and never crashes. Test in Tasks 3 and 6.
4. **Parallel `finding add` from 3 persona subagents at once.** IDs must be unique and sequential, with no overwrites. Test in Task 3 (Promise.all of 20 adds).
5. **Target crashes or is unreachable mid-load-test.** The result has `crashed: true` and there is a critical finding. There must be no unhandled rejection, and the process exits normally. Test in Task 18.

```ts
import { fileURLToPath } from "node:url";

export const CLI = join(dirname(fileURLToPath(import.meta.url)), "..", "dist", "cli.js");

export function tmpRoot(): Promise<string> {
  return mkdtemp(join(tmpdir(), "wreck-it-test-"));
}

export function runCli(
  args: string[],
  opts: { cwd?: string; input?: string } = {},
): Promise<{ code: number; stdout: string; stderr: string }> {
  return new Promise((resolve) => {
    const child = execFile("node", [CLI, ...args], { cwd: opts.cwd, timeout: 120_000 }, (err, stdout, stderr) => {
      const code = err ? (typeof (err as any).code === "number" ? (err as any).code : 1) : 0;
      resolve({ code, stdout: String(stdout), stderr: String(stderr) });
    });
    child.stdin?.end(opts.input ?? "");
  });
}
```

```ts
import { join } from "node:path";
import { mkdir } from "node:fs/promises";

export interface WreckPaths {
  root: string; dir: string; findings: string; shots: string; load: string;
  config: string; run: string; visits: string; discovery: string; personas: string;
  reportHtml: string; reportMd: string; testsDir: string;
}

export function wreckPaths(root: string): WreckPaths {
  const dir = join(root, ".wreck-it");
  return {
    root, dir,
    findings: join(dir, "findings"),
    shots: join(dir, "shots"),
    load: join(dir, "load"),
    config: join(dir, "config.json"),
    run: join(dir, "run.json"),
    visits: join(dir, "visits.jsonl"),
    discovery: join(dir, "discovery.json"),
    personas: join(dir, "personas.md"),
    reportHtml: join(dir, "report.html"),
    reportMd: join(dir, "report.md"),
    testsDir: join(root, "tests", "wreck-it"),
  };
}

export async function ensureDirs(p: WreckPaths): Promise<void> {
  for (const d of [p.dir, p.findings, p.shots, p.load]) await mkdir(d, { recursive: true });
}
```

```ts
import { realpathSync } from "node:fs";
import { fileURLToPath } from "node:url";
import { VERSION } from "./version.js";
import { WreckError } from "./errors.js";

export function buildProgram(): Command {
  const program = new Command();
  program
    .name("wreck-it")
    .description("Wreck your app before your users do.")
    .version(VERSION)
    .showHelpAfterError();
  // Each task adds its own register call here, e.g.:
  //   registerSchemaCommands(program);   (Task 2, from ./commands/schema.js)
  //   registerFindingCommands(program);  (Task 3, ./commands/finding.js)
  //   registerRunCommands(program);      (Task 4, ./commands/run.js)
  //   registerReportCommands(program);   (Task 7, ./commands/report.js)
  //   registerGenTestsCommands(program); (Task 8, ./commands/gentests.js)
  return program;
}

export async function main(argv: string[]): Promise<void> {
  try {
    await buildProgram().parseAsync(argv);
  } catch (err) {
    if (err instanceof WreckError) {
      process.stderr.write(`wreck-it: ${err.message}\n`);
      process.exitCode = err.exitCode;
      return;
    }
    throw err;
  }
}

const isEntry = (() => {
  try { return realpathSync(process.argv[1] ?? "") === realpathSync(fileURLToPath(import.meta.url)); }
  catch { return false; }
})();
if (isEntry) void main(process.argv);
```

```ts
import { z } from "zod";

export const CATEGORIES = ["functional", "ux", "oddity", "chaos", "performance", "security", "accessibility"] as const;
export const SEVERITIES = ["critical", "high", "medium", "low"] as const;
export type Category = (typeof CATEGORIES)[number];
export type Severity = (typeof SEVERITIES)[number];

export const TargetSchema = z.discriminatedUnion("by", [
  z.object({ by: z.literal("role"), role: z.string().min(1), name: z.string().optional(), exact: z.boolean().optional() }),
  z.object({ by: z.literal("label"), value: z.string().min(1) }),
  z.object({ by: z.literal("text"), value: z.string().min(1) }),
  z.object({ by: z.literal("placeholder"), value: z.string().min(1) }),
  z.object({ by: z.literal("testId"), value: z.string().min(1) }),
  z.object({ by: z.literal("css"), value: z.string().min(1) }),
]);
export type Target = z.infer<typeof TargetSchema>;

export const StepSchema = z.discriminatedUnion("action", [
  z.object({ action: z.literal("goto"), url: z.string().min(1) }),
  z.object({ action: z.literal("click"), target: TargetSchema, count: z.number().int().min(1).max(10).optional() }),
  z.object({ action: z.literal("fill"), target: TargetSchema, value: z.string() }),
  z.object({ action: z.literal("select"), target: TargetSchema, value: z.string() }),
  z.object({ action: z.literal("check"), target: TargetSchema }),
  z.object({ action: z.literal("uncheck"), target: TargetSchema }),
  z.object({ action: z.literal("hover"), target: TargetSchema }),
  z.object({ action: z.literal("press"), key: z.string().min(1), target: TargetSchema.optional() }),
  z.object({ action: z.literal("wait"), ms: z.number().int().min(0).max(60_000) }),
  z.object({ action: z.literal("reload") }),
  z.object({ action: z.literal("back") }),
```

```ts
import { readdir, readFile, writeFile, copyFile, mkdir } from "node:fs/promises";
import { existsSync } from "node:fs";
import { join, resolve, relative, extname, sep, isAbsolute } from "node:path";
import { FindingInputSchema, FindingSchema, formatZodError, type Finding } from "./schema.js";
import { wreckPaths, ensureDirs } from "./paths.js";
import { WreckError } from "./errors.js";

const idFile = /^WR-(\d{3,})\.json$/;
const toPosix = (p: string) => p.split(sep).join("/");

async function nextNumber(dir: string): Promise<number> {
  const names = existsSync(dir) ? await readdir(dir) : [];
  let max = 0;
  for (const n of names) { const m = idFile.exec(n); if (m) max = Math.max(max, Number(m[1])); }
  return max + 1;
}

async function reserveId(dir: string): Promise<string> {
  let n = await nextNumber(dir);
  for (let i = 0; i < 10_000; i++, n++) {
    const id = `WR-${String(n).padStart(3, "0")}`;
    try { await writeFile(join(dir, `${id}.json`), "{}", { flag: "wx" }); return id; }
    catch (e) { if ((e as NodeJS.ErrnoException).code !== "EEXIST") throw e; }
  }
  throw new WreckError("could not allocate a finding id");
}

export async function addFinding(root: string, input: unknown): Promise<{ finding: Finding; warnings: string[] }> {
  const parsed = FindingInputSchema.safeParse(input);
  if (!parsed.success) throw new WreckError(`invalid finding:\n${formatZodError(parsed.error)}`, 2);
  const p = wreckPaths(root);
  await ensureDirs(p);
  const id = await reserveId(p.findings);
  const warnings: string[] = [];
  const shots: string[] = [];
  for (const [i, s] of parsed.data.evidence.screenshots.entries()) {
    const abs = resolve(root, s);
    if (!existsSync(abs)) { warnings.push(`screenshot not found: ${s}`); shots.push(s); continue; }
    const rel = relative(p.dir, abs);
    if (rel && !rel.startsWith("..") && !isAbsolute(rel)) { shots.push(toPosix(rel)); continue; }
    const name = `${id}-${i + 1}${extname(abs) || ".png"}`;
    await mkdir(p.shots, { recursive: true });
    await copyFile(abs, join(p.shots, name));
    shots.push(`shots/${name}`);
  }
  const finding = FindingSchema.parse({
    ...parsed.data,
    evidence: { ...parsed.data.evidence, screenshots: shots },
    id,
    createdAt: new Date().toISOString(),
  });
  await writeFile(join(p.findings, `${id}.json`), JSON.stringify(finding, null, 2));
  return { finding, warnings };
}

export async function updateFinding(root: string, id: string, patch: unknown): Promise<Finding> {
  const file = join(wreckPaths(root).findings, `${id}.json`);
  if (!existsSync(file)) throw new WreckError(`finding ${id} not found`, 2);
  if (typeof patch !== "object" || patch === null || Array.isArray(patch)) throw new WreckError("patch must be a JSON object", 2);
  let current: Finding;
  try { current = FindingSchema.parse(JSON.parse(await readFile(file, "utf8"))); }
  catch (e) { throw new WreckError(`finding ${id} is corrupt or incomplete: ${(e as Error).message.split("\n")[0]}`, 2); }
  const r = FindingSchema.safeParse({ ...current, ...(patch as object), id: current.id, createdAt: current.createdAt });
  if (!r.success) throw new WreckError(`invalid update for ${id}:\n${formatZodError(r.error)}`, 2);
  await writeFile(file, JSON.stringify(r.data, null, 2));
  return r.data;
}

export async function listFindings(root: string): Promise<{ findings: Finding[]; errors: { file: string; message: string }[] }> {
  const dir = wreckPaths(root).findings;
  if (!existsSync(dir)) return { findings: [], errors: [] };
  const findings: Finding[] = [];
  const errors: { file: string; message: string }[] = [];
  for (const name of (await readdir(dir)).filter((n) => idFile.test(n))) {
    const file = join(dir, name);
    try {
      const raw = await readFile(file, "utf8");
      if (raw.trim() === "{}") continue; // reserved by a concurrent add, not yet written
      findings.push(FindingSchema.parse(JSON.parse(raw)));
    } catch (e) { errors.push({ file, message: (e as Error).message.split("\n")[0]! }); }
  }
  findings.sort((a, b) => Number(a.id.slice(3)) - Number(b.id.slice(3)));
  return { findings, errors };
}
```

```ts
import { readFile, writeFile, appendFile, rm, mkdir } from "node:fs/promises";
import { wreckPaths, ensureDirs } from "./paths.js";
import { WreckError } from "./errors.js";

export const STAGES = ["preflight", "discover", "personas", "normal", "explore", "chaos", "load", "security", "trace", "report"] as const;
export type Stage = (typeof STAGES)[number];
export const STAGE_STATUSES = ["running", "done", "skipped", "failed"] as const;
export type StageStatus = (typeof STAGE_STATUSES)[number];
export interface RunState { startedAt: string; stages: Partial<Record<Stage, StageStatus>> }

export async function initRun(root: string, opts: { fresh: boolean }): Promise<RunState> {
  const p = wreckPaths(root);
  if (opts.fresh) for (const t of [p.findings, p.shots, p.load, p.visits, p.reportHtml, p.reportMd]) await rm(t, { recursive: true, force: true });
  await ensureDirs(p);
  const state: RunState = { startedAt: new Date().toISOString(), stages: {} };
  await writeFile(p.run, JSON.stringify(state, null, 2));
  return state;
}

async function readState(root: string): Promise<RunState | null> {
  try { return JSON.parse(await readFile(wreckPaths(root).run, "utf8")) as RunState; } catch { return null; }
}

export async function setStage(root: string, stage: Stage, status: StageStatus): Promise<RunState> {
  if (!STAGES.includes(stage)) throw new WreckError(`unknown stage "${stage}" (one of ${STAGES.join(", ")})`, 2);
  if (!STAGE_STATUSES.includes(status)) throw new WreckError(`unknown status "${status}" (one of ${STAGE_STATUSES.join(", ")})`, 2);
  const state = (await readState(root)) ?? (await initRun(root, { fresh: false }));
  state.stages[stage] = status;

      if (typeof v.route === "string" && typeof v.persona === "string") visits.push({ route: v.route, persona: v.persona });
    } catch { /* skip malformed */ }
```

```ts
import { CATEGORIES, type Category, type Severity, type Finding } from "./schema.js";

export const SEVERITY_POINTS: Record<Severity, number> = { critical: 25, high: 10, medium: 4, low: 1 };
export const CATEGORY_CAPS: Record<Category, number> = {
  functional: 60, security: 50, performance: 40, chaos: 30, ux: 20, oddity: 15, accessibility: 15,
};
export type Band = "Not ready" | "Risky" | "Almost there" | "Ship it";
export interface CategoryScore { count: number; deduction: number; cap: number; subscore: number }
export interface ScoreResult {
  score: number; band: Band; criticalCap: boolean;
  categories: Record<Category, CategoryScore>; counted: number; ignoredUnreproduced: number;
}

export function bandFor(score: number): Band {
  if (score >= 90) return "Ship it";
  if (score >= 75) return "Almost there";
  if (score >= 50) return "Risky";
  return "Not ready";
}

export function computeScore(findings: Pick<Finding, "category" | "severity" | "reproduced">[]): ScoreResult {
  const raw = Object.fromEntries(CATEGORIES.map((c) => [c, { count: 0, points: 0 }])) as Record<Category, { count: number; points: number }>;
  let counted = 0, ignored = 0, hasCritical = false;
  for (const f of findings) {
    if (!f.reproduced) { ignored++; continue; }
    counted++;
    raw[f.category].count++;
    raw[f.category].points += SEVERITY_POINTS[f.severity];
    if (f.severity === "critical") hasCritical = true;
  }
  const categories = {} as Record<Category, CategoryScore>;
  let total = 0;
  for (const c of CATEGORIES) {
    const cap = CATEGORY_CAPS[c];
    const deduction = Math.min(raw[c].points, cap);
    total += deduction;
    categories[c] = { count: raw[c].count, deduction, cap, subscore: Math.round(100 * (1 - deduction / cap)) };
  }
  let score = Math.max(0, 100 - total);
  if (hasCritical) score = Math.min(score, 49);
  return { score, band: bandFor(score), criticalCap: hasCritical, categories, counted, ignoredUnreproduced: ignored };
}
```
