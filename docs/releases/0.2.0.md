# wreck-it 0.2.0

Generated regression checks now follow the rendered UI, wait for completed form feedback, and survive regeneration without losing custom assertions or fixtures. The benchmark scorer also requires evidence of the reported behavior before crediting a seeded bug.

## Changes

- Add `waitFor` steps and `value`, `textMatches`, `imageLoaded`, and `linkResolves` assertions. Sweeps test current image/link references and capture screenshots during reproduction.
- Convert recorded app-origin navigation and HTTP URLs into relative paths, allowing `WRECK_IT_BASE_URL` to target a corrected copy.
- Preserve edited and pre-existing WR specs and sidecar fixtures during `gen-tests`. `.wreck-it/generated-tests.json` tracks generated-file hashes; preserved specs produce review warnings. `gen-tests --force` intentionally replaces custom WR specs and removes stale ones.
- Require behavioral signals for benchmark matches; shared files or page snapshots alone earn no credit. Prefer the strongest root-cause match before deduplication and require review for ambiguous matches.
- Require inspected screenshot attachments when presenting browser bugs, and document generated-test limitations.

## Validation

- 216 CLI tests, 10 scorer tests, TypeScript checks, and the production CLI build pass.
- Six focused checks fail at their intended assertions on the buggy app and pass after targeted corrections, with no test timeouts or skips.
- Rescoring the frozen discovery runs yields 19/23 seeded matches for Sonnet and 21/23 for Codex. This is one seeded demo, not a general accuracy guarantee.
- Both the tarball and published npm package passed clean-project checks for version reporting, schema support, generation, preservation, forced regeneration, reports, and an executable generated browser check using a base URL override. ## Install

Version 0.2.0 uses the new npm account and package name `@miyanishar/wreck-it`. The source repository remains [miyannishar/wreck-it](https://github.com/miyannishar/wreck-it). Installations pinned to the older npm scope must switch to the new name for this release.

```bash
npx @miyanishar/wreck-it@0.2.0 --version
```

Existing generated specs are preserved when ownership metadata is absent. Review the warnings and reconcile old assertions with the findings before relying on them. Node.js 22.19 or newer is required; running generated tests also requires `@playwright/test`.
